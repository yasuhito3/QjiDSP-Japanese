## 同梱ファイル

### `Musikvereinsaal_48k_tail.wav`（残響インパルスレスポンス）

`spatial_final_v1〜v6.yml` の `real_hall_L` / `real_hall_R` フィルターから参照されている、
ウィーン楽友協会大ホール（Musikverein）の残響を模したIR（インパルスレスポンス）ファイルです。

**推定される出典**：[Voxengo Free Reverb Impulse Responses](https://www.voxengo.com/impulses/)
（配布者: Aleksey Vaneev）に収録されている「Musikvereinsaal」というIRと、名称が完全に一致しています。
このパックは元々44.1kHz/16bit WAVで配布されており、本ファイルはそこから48kHzへリサンプリングし、
テール（残響尾部）部分を切り出したものと推測されます（波形の直接照合はしていないため、断定はできません）。

> Voxengoのライセンス条件（原文要約）：これらのインパルスファイルの著作権はすべてAleksey Vaneevに帰属します。
> 商用利用を含め、あらゆる目的での無償利用が許可されています。ただし、これらのファイル自体を販売したり、
> 配布によって直接的・間接的な利益を得たりすることはできません。
>
> → Qji（無償・オープンソースのGitHub配布）はこの条件に合致すると考えられます。
> ただし出典が推測に基づくため、可能であれば波形を照合するか、Voxengo配布元へ直接ご確認いただくことをおすすめします。

## 依存ライブラリのライセンス（参考）

pip等でインストールされる外部ライブラリは、それぞれのライセンスに従います。本リポジトリのコードはこれらを
`import`／サブプロセス呼び出しで利用しているのみで、これらのソースコード自体は同梱していません。

| ライブラリ | ライセンス（参考） |
|---|---|
| CamillaDSP / pycamilladsp | MIT / GPLv3（バージョンにより異なる場合があります。公式リポジトリでご確認ください） |
| ffmpeg | LGPL/GPL（ビルド構成により異なる） |
| mutagen | GPLv2+ |
| yt-dlp | Unlicense (Public Domain相当) |
| ytmusicapi | MIT |
| Vosk | Apache-2.0 |
| deno | MIT |
| shairport-sync | 複数ライセンス（詳細は本家リポジトリを参照） |

> `mutagen` はGPLv2+ですが、ソースコード自体は同梱せず、pip経由の別インストールとして案内しています。
> このスタイルは多くのMITライセンスのPython音楽ツールで一般的に採用されている方式です。
